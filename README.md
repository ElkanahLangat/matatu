# matatu-book

A live prototype of a Nairobi matatu mobility platform (matatu.com) — passenger booking, conductor manifest, and management/intelligence dashboard, all synced through shared storage.

## Run it
Just open `index.html` in a browser — no build step needed.

## Deploy on Vercel
1. Push this repo to GitHub
2. Go to vercel.com → New Project → Import this repo
3. Framework preset: Other / Static — no build command needed, output directory: `.`
4. Deploy
